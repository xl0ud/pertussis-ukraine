# Кашлюк в Україні (2016–2025): Моніторинг спалахів

Лаконічна аналітична веб-панель для спостереження за епідемічними спалахами кашлюку (**МКХ-10: А37**) на основі статистичних даних Центру громадського здоров'я МОЗ України.

## Посилання на проєкт

* **Коротке посилання для поширення:** [https://is.gd/kashlyuk](https://is.gd/kashlyuk)
* **Альтернативне посилання:** [https://is.gd/pertussis_ua](https://is.gd/pertussis_ua)
* **Пряме посилання GitHub Pages:** [https://xl0ud.github.io/pertussis-ukraine/](https://xl0ud.github.io/pertussis-ukraine/)
* **QR-код:** файл `qrcode.png`

## Структура та функціонал

1. **Лаконічна бічна панель (Collapsible Sidebar):**
   - Швидкий вибір року (2016–2025 рр., 2024, 2025 тощо).
   - Фільтр за місяцем (зведений весь рік або окремий місяць від січня до грудня).
   - Вибір конкретної області або всієї України.
   - Плавне відкриття та закриття без затримок.

2. **Адаптивна векторна карта України (SVG):**
   - Нативна SVG-картограма без водяних знаків та растрових підкладок.
   - Повністю адаптується до екранів смартфонів, планшетів і ПК.
   - 4-рівнева колірна градація інтенсивності захворюваності:
     - Зелений: фоновий рівень (< 2.0 на 100 тис.);
     - Жовтий: помірний рівень (2.0–10.0 на 100 тис.);
     - Помаранчевий: високий рівень (10.0–30.0 на 100 тис.);
     - Червоний: епідемічний спалах (> 30.0 на 100 тис.).
   - Виділений маркер для міста Києва.
   - Інформаційний рядок над картою без перекриття областей.

3. **Компактні показники (3 картки):**
   - Загальна захворюваність із динамікою приросту або зниження.
   - Інтенсивний показник на 100 тис. населення з порівнянням до багаторічного базису.
   - Епіцентр спалаху та обраний регіон.

4. **Два ключові графіки:**
   - Багаторічна динаміка (2016–2025 рр.) з підсвічуванням вибраного року.
   - Помісячний розподіл випадків (порівняння 2024 та 2025 років) з повними назвами місяців.

5. **Стисла аналітична оцінка:**
   - Пояснення причин спалаху 2024 року (прогалини в АКДП-вакцинації) та стабілізації 2025 року.
